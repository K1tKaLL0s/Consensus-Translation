# 路演讲稿（中文）

各位好，今天演示的是 Cn-Jp Translate 的 MVP 版本。

第一部分，我们强调**来源声明**。无论从 Web、桌面端还是浏览器插件提交翻译任务，用户都需要填写来源声明，这让我们能够明确数据出处、提升可追溯性，并降低错误训练成本。

第二部分是词库能力。我们支持词库导出，并在业务侧强调**词库分类下载**，让不同角色按主题与来源管理术语资产，而不是每次都处理全量数据。

第三部分是训练策略。系统采用**训练无上限分段**机制，对大文本按 chunk 处理，避免单次超大请求带来的不稳定和高重试开销。

接下来演示浏览器插件 MVP：在弹窗中输入文本和来源声明，点击按钮即可请求 `/tasks/translate`，得到受理结果。这是一个最小可跑通闭环，便于快速验证用户路径。

最后总结：

1. 我们先保证关键路径可用（翻译、训练、词库导出）。
2. 通过来源声明与分段机制控制风险和成本。
3. 通过插件脚手架降低接入门槛，支持后续快速迭代。

谢谢大家。
