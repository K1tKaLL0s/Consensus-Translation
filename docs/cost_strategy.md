# 成本策略（MVP）

## 目标

在保证可用性的前提下，以最小投入支撑翻译与训练闭环，并保留后续扩展空间。

## 核心原则

1. **来源声明优先**：每个翻译任务要求填写来源声明，便于审计、追踪与质量回放，减少无效训练带来的成本浪费。
2. **词库分类下载**：词库按主题/来源分类导出（json/csv/xlsx），运营可按需下载，避免一次性全量处理。
3. **训练无上限分段**：训练输入不做总长度上限，采用固定 chunk_size 分段处理，控制单次计算峰值，降低失败重试成本。

## 执行策略

- API 层对翻译请求做来源声明与输入校验，提前阻断低质量请求。
- 训练接口输出 chunk_count，用于估算处理体量与预算。
- 词库导出维持轻量接口，后续再接对象存储与异步导出。

## MVP 阶段边界

- 暂不实现复杂计费系统，仅输出可观测指标（如 text_length、chunk_count）。
- 暂不接入多模型动态路由计费，仅保留统一入口。
