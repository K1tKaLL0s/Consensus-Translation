# 快速开始

共识翻译 Agent 的桌面流程是：输入文本或文件，预检远端调用，运行翻译，人工确认任务，确认词库写回，然后导出结果与审计产物。

默认模式使用本地安全候选和静态测试 provider。真实远端 API key 不会在测试阶段自动调用；启用远端 provider 后，工作台会先显示预算和数据范围，再要求显式确认。

常用入口：

- “翻译工作台”用于文本、文件、候选译文、远端预检、任务确认和导出。
- “项目与任务”用于查看历史 run、状态和人工确认。
- “词库与风格”用于查看待写回术语并确认进入项目词库。
- “帮助中心”可搜索连接器、Provider、运行时、隐私和许可说明。
